# OnlyOne demo content

Demo photos for the [OnlyOne](https://wpinterface.com/themes/onlyone/) WordPress theme by WPInterface.

The theme ships light placeholder images in its patterns. When a site imports a demo with the OnlyOne Starter Sites plugin, the plugin downloads that demo's photos from this repository, checks each one against the SHA-256 in the demo's `manifest.json`, and adds it to the site's media library unchanged.

## Layout

```
<theme version>/<demo>/manifest.json   list of photos, with SHA-256, size and dimensions
<theme version>/<demo>/<photo>.jpg     the photos, as published
```

The files are generated by `npm run demo-packs` in the theme repository. Do not edit them here by hand; a changed photo no longer matches its manifest and the plugin will skip it.
